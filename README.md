## Featured Work

### [ML-Based Network Intrusion Detection Research](https://github.com/lmezzz/mlBased-NIDS-research)

Research-focused ML-NIDS project studying whether intrusion detection models trained on NSL-KDD can generalize to CICIDS 2017.

- Cross-dataset IDS evaluation
- Protocol-aware feature engineering
- Logistic Regression, Random Forest, and SVM comparison
- Precision, recall, and F1-based evaluation
- Failure analysis of ML-based IDS generalization

### [Network MITM / ARP Spoofing Analysis Tool](https://github.com/lmezzz/Network-sniffer-and-arp-spoofing-attack)

Low-level C/libpcap project for studying LAN-level traffic interception in a controlled environment.

- Passive host discovery
- ARP cache poisoning
- DNS query monitoring
- Ethernet, IPv4, UDP, and DNS parsing
- Raw packet crafting and injection
- Multithreaded sniffing/spoofing architecture

### [Concurrent File Sharing Server](https://github.com/lmezzz/Multi-client-File-sharing-service)

C-based multi-client TCP file server focused on systems programming fundamentals.

- POSIX threads
- TCP socket programming
- Reader-writer synchronization
- Bounded buffer design
- Custom application-level protocol design
